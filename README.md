# Project Management System

This is a web-based **Project Management System** developed using **PHP** and **MySQL**. The system allows administrators to manage departments, employees, and performance reviews.

## Features

- **CRUD operations** for managing departments
- Ability to add, update, delete, and view employees
- Performance reviews management system.
